# Ежедневная сводка — v0.3.12

Команды после будущего развёртывания:
- `/daily` — последний завершённый бизнес-день, с учётом границы 08:00.
- `/daily 2026-10-08` — выбранный день.
- `/daily сегодня` — предварительная сводка; сравнение с полными днями отключено.

Сеть и магазины: выручка, количество записей продаж платёжного слоя, средний чек, сумма возвратов. Изменение выручки к предыдущему дню и к дню неделю назад. Для сети разбивка DAY/NIGHT по времени платежа. РЦ исключён через существующие retail_* представления. Данные читаются в одной repeatable-read транзакции.

Возвраты не вычитаются из показателя выручки, согласно текущим правилам проекта. Средний чек — выручка / число платёжных записей продаж; несколько платежей одной продажи считаются отдельно, как в существующей аналитике. Это не новый подсчёт уникальных фискальных чеков.

Нет записей — не доказательство отсутствия продаж. Сравнение использует доступные данные, состав магазинов может различаться между датами. Свежесть и статус загрузки видны внизу отчёта, полнота по-прежнему проверяется /reconcile. Автоматической рассылки нет.

Для сводки изменён app/bot/router.py, добавлены app/services/daily_report.py и tests/test_daily_report.py. Зарплата, схема БД, загрузка и действующие отчёты сохранены. Включено в сборку v0.3.12 вместе с API справочников Core. На сервер автоматически не устанавливалось.

Проверка сборки: 97 локальных тестов. SQL агрегации проверен на тестовой SQLite-базе с продажами, возвратами, двумя платежами одной продажи, удалённой продажей, РЦ и историей сравнения. Подключения к рабочей PostgreSQL не было.
