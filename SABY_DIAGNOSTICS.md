# v0.3.3 — диагностика ответа Saby

Причина отсутствия массива orders пока не установлена: лог v0.3.2 скрывал структуру ответа.
Сборка добавляет диагностику, но не объявляет неизвестный ответ пустым днём и не обходит reconcile.

Разверните сборку с прежними настройками и отключённым auto-sync, затем:

```bash
python -m scripts.bootstrap resume 1
```

Не создавайте новый backfill и не очищайте БД. Если ошибка повторится, отправьте строку
`SABY_RESPONSE_INVALID` целиком: там есть ID точки, окно, страница и типы полей ответа.
Значения полей ответа, токены, содержимое чеков и имена клиентов не выводятся.
После получения структуры можно определить необходимое исправление по фактическому ответу.

Документированный результат — массив orders:
https://saby.ru/help/integration/api/app_sale/get_sale_data

Схема, payroll, shift engine, S3 и точки сохранения backfill не изменены.
