# v0.3.7 — временное отнесение к учётной записи Saby

Решение владельца: пока сохранять продавца из Saby, в том числе когда под его
учётной записью фактически работал другой человек. В дальнейшем реальный график
и фактические смены будут получены из Причал Core. Подключение графика Core в
эту сборку не входит. Учётная запись Saby не является подтверждением фактического выхода.

Не создаём другого продавца и не делим смену по предположению. Правила зарплаты,
идентификации и объединения смен не изменены; итог зарплаты остаётся предварительным
до сопоставления с реальным графиком Core.

Длинная рабочая смена из native-частей теперь может пройти backfill с предупреждением
LONG_NATIVE_SHIFT_KEEP_SABY_ACCOUNT, если единственная причина REVIEW — длительность.
Все части должны присутствовать, их суммы и число чеков должны сходиться с рабочей
сменой; статусы частей — AUTO либо native REVIEW из-за превышения длительности.
Независимая сверка ожидаемых и сохранённых итогов также остаётся обязательной.

Статус REVIEW и длительность сохраняются в БД. В reconcile добавлены warnings и
blocking_review_shifts. Расхождения денег/чеков, отсутствие продавца, fallback,
неоднозначные или потерянные части по-прежнему блокируют загрузку.

Для Яблокова 14, 10 июля, продавец остаётся Сексяева Е.В. Смена 23,350 часа
не делится искусственно и не превращается в две выплаты фиксированной части.

После обновления, с обоими флагами auto-sync=false:

```bash
python -m scripts.bootstrap resume 2
```

Данные и stores не очищать. При новой блокирующей ошибке смотрите reconcile-report 2.
