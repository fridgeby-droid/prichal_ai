# Контракт повторов фотографий — дополнение для Причал Core

Сторона AI подготовлена в исходниках; пока не собрана и не установлена.

При ошибке GET /api/v1/core/price-list-images/{reference} ответ содержит:

```json
{
  "schema_version": 1,
  "complete_snapshot": false,
  "error": {
    "code": "SABY_IMAGE_UPSTREAM_ERROR",
    "retryable": true,
    "retry_scope": "image",
    "refetch_price_list": false
  }
}
```

Сохраняется прежний HTTP-статус ошибки, добавляются поля. Retry-After: 30 для временных ошибок, 120 для ограничения частоты. 404, неправильный тип или размер изображения — retryable=false. Не подменять ошибку пустым изображением или удалением имеющегося файла.

Core должен сохранять полный успешно полученный ассортимент независимо от ошибок фото. Для каждой картинки хранить ID, download_path, состояние, число попыток и время следующей попытки. Ошибка одного файла не требует повторно запрашивать прайс: используйте сохранённый download_path, тот же серверный ключ и отдельную очередь изображений. При отсутствии сохранённого файла — заглушка, при ошибке обновления — прежнее фото. ETag/If-None-Match и 304 продолжают действовать.

Этот документ не означает, что реализация очереди Core уже изменена. S3, миниатюры и очередь Core остаются ответственностью Core. Секреты Saby или Core API нельзя передавать в браузер. Существующая загрузка бонусов с этой очередью не объединяется.
