# v0.3.8 — устойчивость запросов Saby

Наблюдавшаяся ошибка httpx.ConnectError / No address associated with hostname
возникла при разрешении адреса для HTTP-запроса, до reconcile. Из этого лога
нельзя установить, был ли сбой временным или постоянным на стороне хостинга.

Изменения:

- До четырёх попыток для ошибок соединения, таймаута, чтения, удалённого протокола
  и HTTP 429/502/503/504. Паузы 1, 2, 4 секунды; числовой Retry-After до 30 секунд
  учитывается. При более длинном/неподдержанном Retry-After загрузка останавливается.
- Лимит одновременно выполняемых HTTP-запросов действует на все вложенные окна
  Saby; не больше min(SYNC_CONCURRENCY, 4), минимум 1.
- При ошибке или отмене пакета остальные запросы отменяются и ожидается их завершение.
- Неудачный запрос не подменяется пустым результатом. Checkpoint блока не продвигается.
- Данные, reconcile, payroll и решение о временной учётке Saby не изменены.

После обновления оставьте auto-sync выключенным и продолжите существующий запуск:

```bash
python -m scripts.bootstrap resume 2
```

Если сеть нестабильна, можно задать SYNC_CONCURRENCY=2 и перезапустить приложение.
Это уменьшает нагрузку, но не устраняет постоянную неисправность DNS хостинга.
Если после четырёх попыток ошибка повторяется, проверьте у хостинга разрешение
имён api.sbis.ru и online.sbis.ru и исходящий HTTPS из контейнера. БД не очищайте.

Проверено 69 тестов с подменой HTTP, включая кратковременный/постоянный DNS-сбой,
Retry-After, предел параллельности и отмену соседних запросов.
Сеть реального контейнера в этой среде не проверялась.
