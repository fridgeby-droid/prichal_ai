
## Источник и границы проверки

Использован документированный [метод Saby чтения бонусов заказа](https://saby.ru/help/integration/api/app_sale/sale_bonuses/know_bonuses_off): `GET /retail/order/{externalId}/bonus-read`.

Метод принимает UUID заказа. Скрипт берёт UUID из сохранённого поля `Key` как кандидата. Соответствие `Key` параметру `externalId` ещё не подтверждено; оно явно отмечено как гипотеза. Числовой ID продажи не подставляется вместо UUID.

Это проверка двух заказов, не полный журнал бонусных операций. `bonusInc` описывает бонусы к начислению, а не гарантированно проведённое историческое начисление. Балансы относятся к моменту чтения. Доступные к списанию суммы не заменяют фактическое списание `bonusDec`.

Скрипт не сохраняет бонусные факты и не изменяет продажи. Используется обычная инициализация существующей БД. Выполняются только GET-запросы к бонусному методу, с паузой между двумя проверками. UUID, номера карт, контакты и секреты в результат не выводятся.

## Как читать ответ

- `REFERENCE_VALUES_MATCH`: направление и выбранная сумма совпали с контрольным примером. Это ещё не подтверждает полноту истории; `mapping_confirmed` остаётся false.
- `REFERENCE_NOT_MATCHED`: вернувшиеся значения не совпали. Не заменять их ожидаемыми числами.
- `HTTP_ERROR`: статус ответа Saby; 404 не означает нулевые бонусы.
- `NO_UUID_CANDIDATE`: в локальной продаже нет допустимого UUID для проверки.
- `LOCAL_SALE_NOT_FOUND` / `LOCAL_REFERENCE_MISMATCH`: контрольная запись отсутствует или не соответствует ожидаемому номеру и дате.
- `ACTION_MISSING_OR_UNSUPPORTED`, `INVALID_RESPONSE`, `SOURCE_ERROR`, `BONUS_BALANCE_ERROR`, `INVALID_AMOUNTS`: ответ нельзя использовать как подтверждённый бонусный факт.

Неизвестные значения остаются null, не превращаются в ноль. `complete_history: false` и `facts_saved: false` — ожидаемые признаки диагностического режима. Сохраните и передайте JSON результата для выбора следующего шага.

Скидка с названием «Начисление бонусов» сама по себе не определяет направление операции. Из оплаченной суммы 1750.15 повторно вычитать 36 нельзя.
