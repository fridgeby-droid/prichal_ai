# Причал AI v0.3.54

Добавлены локальные отчёты фактической себестоимости, загрузчик текущих остатков с историей наблюдений, кнопки и CSV. Подробности и настройки: INVENTORY-AND-COSTS.md.

## После установки

Проверьте версию:

```sh
python -c "print(__import__('app.version', fromlist=['APP_VERSION']).APP_VERSION)"
```

Проверьте фактическую себестоимость в сохранённых продажах Батумской:

```sh
python -m scripts.inventory costs 2026-11-13 2026-11-13 --point-id 5635
```

Найдите контрольное поступление:

```sh
python -m scripts.inventory receipt --date 2026-11-13 --number УТ-121230
```

Эта проверка не выполняет документ в Saby и не загружает его строки в учёт движений. Автоматический импорт поступлений ещё не включён: необходима проверка склада, проведения и состава ответа. Номер документа не подтверждает принадлежность магазину.

Для настройки остатков понадобятся реальные ID организации, склада, товаров и их складские единицы. Автоматический опрос не запускается. Таблица inventory_observations создаётся при первом явном stock-load --apply; продажи не изменяются и повторно не загружаются.

В Telegram откройте свежее /menu → Товары. Маржа неизвестна до согласования налоговой базы; фактическая себестоимость и её покрытие доступны независимо. Комплекты, вложенные позиции и неподтверждённые нулевые стоимости не используются для расчёта маржи. Наблюдения нулевого остатка не доказывают непрерывную длительность отсутствия.

Проверки выполнялись локально на подставных данных. Авторизация, фактическая форма ответа Saby и права приложения требуют проверки на вашем сервере.
