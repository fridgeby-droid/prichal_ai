# Причал AI 0.3.52 — кнопочное меню

## Открытие

После установки отправьте боту `/start` или `/menu` один раз. Появится постоянная кнопка **☰ Меню**. Текстовые вопросы и прежние команды сохранены.

Разделы:

- **Обзор сети:** итоги, сравнение периодов, разбор изменений, утренний обзор.
- **Магазины:** карточка, итоги и дневная/ночная смены.
- **Продавцы:** средний чек, сравнение учёток в сопоставимых условиях, количество проданных товаров.
- **Товары:** лидеры, категории, количество, модификаторы.
- **Покупки:** средний чек, наполняемость, возвраты.
- **Клиенты и бонусы:** группы по давности, начисления/списания, впервые наблюдаемые и повторные клиенты.
- **Задачи:** список, создание, карточка, пауза, возобновление, отмена с подтверждением.
- **Уведомления:** общий переключатель, отдельно утренний обзор и результаты задач, изменение времени.
- **Данные:** статус загрузки и локальная сверка.

## Работа с отчётом

Кнопки ведут к выбору магазина (или сети без РЦ), смены для поддерживаемых отчётов и периода. Периоды: последний закрытый бизнес-день, 7 закрытых дней, последний полный месяц, с начала месяца, свой диапазон. Для сверки максимум 7 дней. Все даты показываются в заголовке; граница бизнес-дня 08:00.

Свой диапазон вводится одним сообщением: `2026-10-01 2026-10-31`. Поиск товара — часть названия, совпадения не объединяются в один товар. Можно выбрать все товары. Для клиентов кнопки 0–29, 30–59, 60–89, 90+ дней либо все. Дата окончания отчёта — дата отсечения давности, нижняя граница не ограничивает поиск последнего визита.

Кнопки результата:

- **Другой период** — повторный выбор.
- **Подробнее** — полная текущая страница существующего отчёта.
- **Сравнить с предыдущим периодом** — для сводки, товаров, категорий, смен и разбора изменений. Полный календарный месяц сравнивается с предыдущим календарным месяцем; иной интервал — с предыдущим равной длины. База подписывается в результате. Другую произвольную базу можно задать свободным текстом.
- **Скачать CSV** — только там, где поддерживается полный экспорт: средние чеки, количество, модификаторы, клиенты, возвраты, бонусы, сравнение учёток и новые/повторные клиенты. Все строки выбранных фильтров, без ограничения текущей страницей, до 45 МБ. В сетевых/товарных агрегатных топах CSV намеренно не предлагается как полный список: используйте «Количество товаров» для полного экспорта.
- **Следующая страница / Первая страница** — когда источник отдаёт следующую страницу. Краткий вид показывает первые 10 строк текущей страницы; «Подробнее» показывает все строки страницы.

Показатели считают существующие сервисы, без обращений к языковой модели или Saby. «Разбор изменений» кнопкой показывает измеренные вклады; объяснение и гипотезы можно запросить обычной фразой. Результат кнопочного отчёта записывается в память диалога с областью, периодом и фильтрами: после него работают продолжения «а ночью?» и «пришли этих клиентов файлом».

## Задачи и уведомления

Доступны только в личном чате разрешённого пользователя. Время по умолчанию 10:00, Екатеринбург; установка не включает подписку автоматически. Откройте «Уведомления» и включите общий переключатель и нужные типы сообщений.

Новая задача: магазин → смена → показатель → 7/14/30 дней либо свой срок 1–90 → подтверждение. По умолчанию проверяется положительный рост. Процентный порог можно задать обычной фразой. При отсутствии базы задача сохраняется и ждёт данные, как в v0.3.51. В карточке есть базовые даты, срок, статус и результат. Отмена требует отдельного подтверждения.

## Изоляция и сохранение

Меню хранится в PostgreSQL `app_meta` отдельно для пользователя, чата и темы и действует 24 часа. Новое меню делает старые кнопки недействительными. Действия разрешены только для кнопок текущего меню; подмена callback-параметров отклоняется. Чужие кнопки в группе не дают доступа к чужим настройкам/задачам. Кнопки задач используют пользователя нажавшего кнопку, а не автора сообщения бота.

Если открыта форма ввода, следующее текстовое сообщение воспринимается как её поле. Чтобы вернуться к свободному разговору, нажмите «Назад» или «Главное меню». Состояния задач и подписки от закрытия меню не меняются. Настройки автозагрузки, Core, прайсы и исторические чеки не изменяются.

## Проверка после установки

1. `/start` → все 9 разделов, постоянная кнопка «☰ Меню».
2. Магазины → итоги → Батумская → полный месяц. Проверьте магазин и даты, затем сравнение.
3. Товары → количество → Батумская → все смены → «пакет МАЙКА» → свой период → CSV. Фильтры и суммы должны совпадать с текстовой командой.
4. Клиенты → сеть → 30–59 → период → CSV. Экспорт должен включать всю группу.
5. Уведомления → переключить обзор, вернуть обратно, изменить время на 10:00.
6. Задачи → новая → Батумская → дневная → выручка в день → 7 дней → создать. Затем пауза/возобновление; отмена только после подтверждения.
7. Нажмите старую кнопку: должен быть ответ об устаревшем меню без выполнения действия.
8. После кнопочного отчёта напишите уточнение обычным текстом — магазин и период должны сохраниться.

Доставка Telegram, вид на телефоне и боевые данные проверяются после установки. Локальные тесты работают с подставными ответами сервисов и не отправляют сообщений пользователям.
