# Причал AI v0.2.12 — Native Shift Anchoring

Исправляет распределение выручки на границах смен.

## Главная логика

Раньше каждый payment сначала жёстко делился по часам:
- DAY: 08:00–19:59
- NIGHT: 20:00–07:59

Из-за этого реальная Saby Shift могла быть разрезана, если:
- предыдущая NIGHT закончилась после 08:00;
- следующая DAY началась до 08:00.

Теперь порядок другой:

1. Payments сначала группируются по реальному Saby `Shift` / `ShiftNumber` без разрезания по 08:00.
2. Для всей Saby Shift определяется DAY/NIGHT по большинству чеков.
3. Для всей Saby Shift определяется одна operational `business_date`.
4. Только затем смена делится по Seller для employee attribution.
5. Несколько cash shifts одного продавца могут консолидироваться в одну employee work shift.

То есть 08:00 и 20:00 — ориентиры, а не жёсткий нож для реальной кассовой смены.

Итого: 2 096,90 ₽ — ровно всё расхождение.
