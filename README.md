# Причал AI v0.2.4 — Safe Pagination

Исправляет зацикливание `retail/order/list`.

## Причина

Saby документирует `page` и `pageSize` (максимум 100), но для
`retail/order/list` в открытой документации нет `hasMore`.

В нашем контуре API мог возвращать полную повторяющуюся страницу,
из-за чего старая логика продолжала идти page=0,1,2... пока не достигала
`SABY_MAX_PAGES_PER_POINT`.

## Новая остановка пагинации

Запрос прекращается, если:
1. страница пустая;
2. пришло меньше 100 записей;
3. полностью повторилась уже полученная страница;
4. новая страница не содержит ни одного нового `Sale`/`Key`.

Продажи дополнительно дедуплицируются в памяти до записи в Neon.

## Отмена sync

Во время ручного `/sync` теперь работает:

`/cancelsync`

Запуск в `sync_runs` получит статус `CANCELLED`.

## Переменные

Рекомендуется:

```env
SABY_MAX_PAGES_PER_POINT=30
SYNC_CONCURRENCY=4
```

30 — это только аварийный верхний предел. В нормальной работе цикл должен
останавливаться значительно раньше по фактическому концу/повтору страниц.

## После деплоя

1. `/ping`
2. `/sync 1`
3. посмотреть лог — один магазин не должен уходить в page=12, 15, 17...
4. `/shiftdebug вчера`
5. `/rebuildshifts 4`
6. `/shifts вчера`
