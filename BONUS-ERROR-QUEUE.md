# v0.3.35 — продолжение после ошибки отдельной продажи

После установки продолжите текущий общий запуск:

```console
python -m scripts.saby_data resume
```

Завершённые этапы магазинов, продаж, сверки, каталога и прайсов будут пропущены. Бонусы успешно обработанных продаж тоже не загружаются заново.

При ошибке отдельной продажи выполняются прежние ограниченные повторные попытки. Затем сохраняется ERROR, выводится `Bonus deferred: point=... sale=... code=...`, и начинается следующая продажа. Ошибочная продажа исключается из очереди текущего прохода, поэтому бесконечного цикла на ней нет. Предыдущий ответ, если был, сохраняется, но не считается актуальным. Неизвестные бонусы не становятся нулевыми.

Если проход закончен с ошибками, бонусный этап возвращает PARTIAL_ERRORS, а общий запуск остаётся ERROR с bonus_result. Это не означает, что загрузка остановилась на первой ошибке: остальные записи уже обработаны. Повторная команда resume заново проверяет оставшиеся ошибки и новые записи; успешные ответы пропускаются.

При пяти ошибках подряд или проблемах авторизации/ограничении частоты загрузка останавливается, чтобы не обходить весь аккаунт при общем сбое. Итог STOPPED содержит причину GLOBAL_OR_REPEATED_FAILURE. Повторять следует после устранения причины или окончания ограничения Saby.

Для отдельного загрузчика команда прежняя: `python -m scripts.bonuses load --all`. PARTIAL_ERRORS возвращает код выхода 1, чтобы неполная загрузка не считалась успешной. Состояние очереди: `python -m scripts.bonuses plan`; состояние общего запуска: `python -m scripts.saby_data check`.

Правила о неизменности старых чеков и исключении продаж без клиента сохранены. Обновление не сбрасывает прогресс, не меняет схему БД и не отправляет изменения в Saby.

Локальные тесты проверяют продолжение после HTTP 500, исключение ошибочной записи внутри прохода, остановку при общих сбоях и сохранение имеющихся данных. Живой запрос продажи 8812 точки 5590 в этой среде не выполнялся.
