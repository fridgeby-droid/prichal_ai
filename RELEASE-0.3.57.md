# Причал AI 0.3.57 — покупки и бонусные карты

Добавлен get_purchase_loyalty: количество, суммы покупок, средние и доли по группам
с подтверждённой картой, без Customer (без карты по правилу владельца), unknown.
Поддерживаются порог суммы, магазин, учётка продавца, смена и фильтры известных
положительных начислений/списаний. Список покупок постраничный, по 20 строк.

Начисления — bonusInc, бонусы к начислению, не подтверждённый журнал проведённых
операций. Списания — известное bonusDec. Баллы не переводятся в рубли.
Учитываются только свежие OK наблюдения. Ошибки и неизвестные значения не равны нулю.
Рейтинг магазинов по списаниям пока не реализован. CSV нового отчёта не поддерживается.

Подробности: PURCHASE-REPORTS.md. Для установки сохраните текущие переменные среды
Bothost и перезапустите приложение. Миграция, новые ключи и повторная загрузка Saby
не нужны. Отчёты используют уже сохранённые бонусные ответы.

Проверка после установки:
1. Сколько покупок больше 500 рублей с бонусной картой было в Батумской в октябре 2026?
2. Сравни средний чек с картой и без карты в Батумской за октябрь 2026.
3. Сколько бонусов к начислению и списано по Батумской за октябрь 2026?
4. Покажи покупки со списанием бонусов по Батумской за октябрь 2026.

Локальная проверка реализации: 596 тестов успешно. Реальные результаты и доступ
помощника к новым инструментам проверить после установки. Предыдущие функции сохранены.
