# Причал AI 0.3.48

Пакет уточнений отчётов по проверкам в Telegram.

- Разбивка по сменам передаёт количество платежей, среднее количество за календарный бизнес-день и взвешенный средний чек обеих сравниваемых выборок.
- Недельные интервалы рассчитываются кодом. Обе крайние неполные недели отмечаются; пустая неделя не получает нулевое среднее. Число наблюдаемых дней передаётся отдельно от календарного знаменателя.
- Изменение количества при отсутствии товара в одном периоде остаётся неизвестным. Вклад доступных товарных сумм в общий итог сохраняется отдельно.
- Клиенты упорядочены по давности покупки по убыванию, затем по числовому ID по возрастанию.
- Уточнены инструкции агенту: все запрошенные показатели в каждом разрезе, отсутствие вывода об устойчивом тренде по одному падению, короткие названия бонусных показателей, без общих повторяющихся предупреждений. Конкретные ошибки и пропуски остаются видимыми.
- `/loadstatus` и `python -m scripts.saby_data status` показывают краткий статус из локальной БД, счётчики бонусов и план следующего запуска. Статус не запускает загрузку и не подтверждает работу процесса по одной отметке RUNNING. Для подробностей остаётся `check`.
- CSV доступен также для средних чеков и динамики. Платёжные и товарные/продажные основания разделены; экспорт содержит фильтры и период. Для товаров и клиентов CSV содержит полный отфильтрованный список, независимо от страницы сообщения.

## Проверка после установки

В консоли:
```
python -c "print(__import__('app.version',fromlist=['APP_VERSION']).APP_VERSION)"
python -m scripts.saby_data status
```

В Telegram:
```
/loadstatus
/avgcheck 2026-10-01 2026-10-31 point=5635 csv=true
/trend 2026-10-01 2026-10-31 point=5635 csv=true
/clients 2026-07-01 2026-10-31 min=30 max=59 csv=true
/itemqty 2026-10-01 2026-10-31 point=5635 query="пакет МАЙКА" match=exact csv=true
```

Проверить свободным текстом: сравнение сентября и октября по Батумской 5 с выручкой, платежами и средним чеком отдельно по дневной и ночной сменам; недельную динамику октября; отсутствие количества ИСЕТСКОГО в октябре.

CSV отправляется командным обработчиком Telegram, а не обещанием языковой модели. Готовые расчёты проверяются локальными тестами; формулировки живой модели и серверная БД требуют проверки после установки.

Миграция данных и повторная загрузка старых чеков для этой версии не требуются. Настройки автоматической загрузки не изменены.
