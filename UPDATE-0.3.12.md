# Установка v0.3.12 в Bothost

Полный архив приложения на основе v0.3.11. Добавлены /daily и защищённый GET /api/v1/core/directories. Исключение РЦ, импорт планов и правила загрузки сохранены. Зарплата и график не изменены.

1. Загрузить архив в Bothost обычным способом, сохранив существующие переменные окружения PostgreSQL, S3, Telegram и Saby. Не заменять их примером .env.example.
2. Для API добавить CORE_DIRECTORY_API_KEY: отдельный случайный секрет не короче 32 символов. Сгенерировать в менеджере паролей, хранить только на серверах AI и Core. Не публиковать в чате и не передавать в URL. Без ключа сводка работает, а API возвращает 503.
3. Сохранить текущие AUTO_SYNC_ENABLED=true, AUTO_SYNC_ON_START=true, SYNC_INTERVAL_MINUTES=60, SYNC_RECENT_DAYS=3. Перезапустить приложение.
4. В боте: /version — версия 0.3.12, build daily-core-directories.
5. /daily 2026-10-08 — контрольная сводка за проверенный день; /daily — последний завершённый бизнес-день.
6. /reconcile 2026-10-08 — ожидается OK. В логах проверить завершение автоматической загрузки.
7. После настройки ключа проверить API серверным запросом: без ключа 401, с Authorization: Bearer <ключ> — 200 и справочники без РЦ. Для текущего набора ожидается 12 магазинов. Детали в CORE-DIRECTORIES-API.md.

Историю загружать повторно, сбрасывать базу или повторно импортировать планы не нужно. /daily читает базу и не запускает Saby.

Core самостоятельно не подключается: в нём ещё требуется реализовать серверную загрузку справочников и экран подтверждения связей. Контракт находится в CORE-DIRECTORIES-API.md. API не меняет соответствия сотрудников.

На рабочем сервере сборка автоматически не установлена. Тесты выполнялись локально без рабочей базы и внешних сервисов.
