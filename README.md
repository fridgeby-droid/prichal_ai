# Причал AI v0.1

Первая рабочая сборка отдельного директорского Telegram AI-агента.

## Уже работает

- доступ только для Telegram user_id руководителя и операционного директора;
- OpenAI Agents SDK;
- сервисная авторизация Saby;
- список Retail-точек;
- сводка продаж сети за дату;
- сводка конкретного магазина;
- топ товаров по чистой выручке;
- фактическая себестоимость и валовая прибыль, если Saby возвращает `TotalCost`;
- `/health` для Bothost;
- read-only проверка доступности Причал Core.

## Первый тест

После запуска:

1. `/ping`
2. `/saby`
3. `Как вчера отработала сеть?`
4. `Покажи топ-10 товаров вчера`
5. `Как вчера отработал <магазин>?`

## Безопасность

v0.1 полностью read-only. AI не создаёт и не изменяет данные в Saby/Core.
