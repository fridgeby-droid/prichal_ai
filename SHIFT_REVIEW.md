# v0.3.6 — диагностика смены REVIEW

Сборка добавляет чтение рабочей смены и именно тех кассовых частей, которые перечислены
в её cash_shift_keys. Алгоритм объединения, зарплатные правила и блокировка REVIEW не изменены.
100% confidence не означает AUTO: длительность может превышать лимит при достоверном источнике.

После обновления выполните одну команду в Telegram:

```text
/shiftinspect 5598 2026-07-10
```

Либо штатную команду приложения в консоли:

```bash
python -m scripts.bootstrap shift-report 5598 2026-07-10
```

Отчёт содержит начало/конец в бизнес-часовом поясе, длительность, источник, статус,
идентификаторы кассовых смен и текущие лимиты. Чтение проходит в read-only транзакции.
CLI, как и другие команды bootstrap, сначала выполняет штатную инициализацию схемы.
Данные продаж и смен отчёт не пересчитывает и не изменяет.

WORK_DURATION_EXCEEDS_LIMIT — объединённая смена длиннее текущего лимита.
CASH_COMPONENT_REQUIRES_REVIEW — хотя бы одна кассовая часть имеет статус не AUTO.
Отчёт объясняет сохранённый статус по текущим настройкам; если настройки изменялись,
они могут отличаться от использованных при построении.

Причина конкретной смены Яблокова 14 пока не подтверждена её временными границами.
Не увеличивайте лимит и не снимайте REVIEW до проверки отчёта. Resume 2 пока не требуется.
