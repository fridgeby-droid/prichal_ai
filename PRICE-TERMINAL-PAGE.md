# Исправление завершения прайсов — v0.3.34

По диагностике прайсов 81 и 82 точки 23109 Saby возвращает последнюю страницу как `nomenclatures: {}` с `outcome.hasMore: false`. Теперь такое сочетание принимается как пустая завершающая страница. Ранее полученные товары сохраняются в полном результате. Курсоры 1683 и 2084 не свидетельствуют о повреждённых товарах.

Непустой объект, отсутствующее поле, null, отсутствующий/небулевый hasMore, пустой ответ с hasMore=true и явные ошибки по-прежнему отклоняются. Изменение не распространяется на список прайсов priceLists. Общий разбор nomenclatures используется также каталогом; правило завершения одинаковое.

После установки:

```console
python -m scripts.price_lists 23109 81 --check-image
python -m scripts.price_lists 23109 82 --check-image
```

Ожидается complete_snapshot=true и количество товаров. Проверка картинки скачивает один пример, если фото есть. В случае иной ошибки результат остаётся неполным. Живые запросы в этой среде не выполнялись.

Если общий запуск обслуживания остановился на прайсе, продолжите его командой `python -m scripts.saby_data resume`. Для загрузки в Core повторите импорт прайса в Core: диагностическая команда сама туда данные не отправляет.

Локально пройдено 298 тестов, включая завершение после обоих курсоров, сохранение накопленных товаров и отклонение ошибочных форматов. Действующие API, схема БД и правила загрузки сохранены.
